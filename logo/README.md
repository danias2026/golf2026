# Golf & Games Classic — logo

The official event logo is the **wordmark** from last year's flyer design (approved Nov 2026): "GOLF & GAMES" with a large silver ampersand, "CLASSIC" below, in Playfair Display.

## Files (`wordmark/`)
All SVG and PDF files are pure vector outlines (no fonts needed).

| File | Use |
|---|---|
| `golf-games-classic-wordmark.svg / .pdf / .png` | Full color: gold #DEC000 + silver ampersand #B4BAB4. Default, on dark green felt or any dark ground. |
| `golf-games-classic-wordmark-kicker.svg / .pdf / .png` | Same with "TWO JCCS. ONE TOURNAMENT." above (off-white #F4F3EE). Headers, banners. |
| `golf-games-classic-wordmark-white.svg / .png` | All white, for photos and single-color dark uses. |
| `golf-games-classic-wordmark-kicker-white.svg / .png` | Kicker version, all white. |
| `golf-games-classic-wordmark-gold.svg / .pdf / .png` | All gold, for foil or single-color print. |
| `golf-games-classic-wordmark-on-felt.jpg` | Kicker wordmark on the felt background with the gold frame (3000 × 1600). Presentations, web. |
| `instagram-avatar-1080.png` | Instagram profile picture: wordmark on felt with a round gold ring (survives the circle crop). |

PNG files are 4000 px wide with a transparent background.

## Rules
- Keep the wordmark on dark grounds (felt green or navy-black). The full-color version is not for white backgrounds; use the gold version on light paper only if needed.
- Never split "GOLF & GAMES" and "CLASSIC" onto other lines, stretch, recolor or retype it.
- Clear space around it: at least the height of the letter "C" in CLASSIC.
- Host logos (MARJCC, MBJCC) go at the top of every piece; GMJF alone at the bottom.
