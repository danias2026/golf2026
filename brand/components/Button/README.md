Square, all-caps buttons in the deco face.

**Provide:** a label (2 to 3 words, ALL CAPS by style) and a link.

- `gg-btn--red`: the single most important action on the piece (Save the date, Register now). One per screen or email.
- `gg-btn--primary`: other actions (Learn more, See schedule).
- `gg-btn--ghost`: low-key actions (Become a sponsor, Contact us).

Minimum height 48px. Focus shows a 3px `focus` ring. In email, rebuild the red button as a table cell with the `email` family; web fonts do not load in most email programs.
