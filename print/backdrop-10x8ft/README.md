# Banner de entrada 10 × 8 ft (horizontal) — Save the Date

Un solo banner para la entrada del JCC.

- `golf-games-classic-backdrop-10x8ft.pdf`: archivo para imprenta. 122 × 98 in = 120 × 96 in (10 × 8 ft) + 1 in de sangrado por lado. Vectorial: logo del evento, formas y textos (fuentes incrustadas).
- `preview.png`: vista previa.
- `src/`: fuente (`node src/render.js` regenera PDF y preview).

Notas para imprenta:
- Margen de seguridad de 3 in dentro del corte; nada importante está más cerca.
- Los logos de MARJCC, MBJCC y GMJF van como imagen (no tenemos sus vectores). Pedir sus archivos vectoriales (AI/EPS/SVG/PDF) antes de imprimir para máxima nitidez.
- Pensado para leerse de lejos: pocos mensajes y texto grande.
